# 像素小人 · 橙发女孩

Claude Code 状态小人的像素素材工程。真实分辨率 119×129，32 色调色板，显示时按整数倍放大并使用最近邻缩放。

## 目录

- runtime/：运行时需要的全部文件
  - sprites/：分层图层，画布统一 119×129
  - manifest.json：叠放顺序与动画参数（后发 800ms 一帧，"中、左、中、右"循环；眨眼为半闭 60ms、闭 90ms、半闭 60ms，每 2.5 到 5.5 秒随机一次）
  - pixel-idle.gif：空闲动画成品（透明背景、1 倍大小，每个 3.2 秒循环眨一次眼）
- preview/pixel-idle.html：浏览器预览页，可调帧时长、背景、放大倍数
- source_images/：AI 生成的原图，编号即用途；x_ 开头的是被淘汰的版本，留作参考
- pipeline/：处理脚本与中间数据

## 叠放顺序

后发（hair_c / hair_l / hair_r 之一）→ 主体 main → 眼睛补丁（眨眼时）→ 嘴巴补丁（说话时）。补丁只含变化的像素，其余透明。

## 处理流程

1. grid.py：估计每张原图的像素网格周期和相位，按格子中心取中位色，还原成真实分辨率（输出 lr.npz）
2. build.py：第一版流程。对齐、k-means 统一 32 色调色板（palette.npy）、提取眼睛和嘴巴补丁、手臂层
3. v2.py：把主体图和三张后发按原图网格采样（输出 lr2.npz），检查对齐与摆动幅度
4. build2.py：第二版流程。量化新图层、清除孤立像素、裁剪到 119×129 并导出
5. idle.ts + idle.html：预览页源码，用 esbuild 打包后把图层以 data URI 内联

脚本里的输入路径是对话环境里的绝对路径（/mnt/user-data/uploads），本地重跑时需要改成 source_images 下对应的文件名。

## 生成新差分的经验

- 每条修改开一个新对话，只上传原始全身图（后发差分则上传 08 号后发图），只发一条指令
- 提示词里写明"其他所有像素保持完全不变，画布尺寸、位置、背景都不变"
- 摆动类差分要给出具体幅度，发梢偏移约 8 到 12 个像素格效果最好
- 背景统一用 #FF00FF 品红
