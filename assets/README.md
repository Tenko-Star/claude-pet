# 像素小人 · 橙发女孩

Claude Code 状态小人的像素素材工程。真实分辨率 119×129，32 色调色板，显示时按整数倍放大并使用最近邻缩放。

## 目录

- runtime/：运行时需要的全部文件
  - sprites/：图层，角色画布统一 119×129；`main_*` 是各状态的整张主体，`fx_*` 是特效小图
  - manifest.json：叠放顺序、各状态用哪张主体、动画参数
  - pixel-idle.gif：空闲动画成品（透明背景、1 倍大小）
- preview/
  - state-demo.html：七状态演示页，内嵌 runtime/manifest.json 同款参数，可手动切换或按典型任务顺序自动播放
  - pixel-idle.html：早期的空闲动画预览页
- source_images/：AI 生成的原图，编号即用途；x_ 开头的是被淘汰的版本，留作参考
- pipeline/：处理脚本与中间数据

## 状态

| 状态 | 对应 hook | 主体 | 动画 |
| --- | --- | --- | --- |
| 空闲 idle | SessionStart、完成之后 | main.png | 后发摆动、眨眼 |
| 思考 think | UserPromptSubmit，工具调用之间 | main_think_mid.png → main_think.png | 食指抵唇，头顶三个点依次亮起 |
| 工作中 working | PreToolUse | main_work.png / main_work_tap.png | 手部下移 1 格当按键，一阵连按 3 到 6 下再停顿 |
| 等待确认 notice | Notification | main_notice_mid.png → main_notice.png | 抬手一次后停住，头顶感叹号弹出、浮动，每 3.5 秒重弹 |
| 完成 done | Stop | main_done.png | 双手合拢、眯眼笑，身边星星闪烁，2.2 秒后回空闲；主体自带眼睛表情，不叠眨眼层 |
| 错误 error | StopFailure | main_error.png | 双手捂脸、> < 眼，头顶小乌云翻滚、汗珠；停留到下一次提交提示词 |
| 睡觉 sleep | 长时间无活动 | main.png + eye_sleep.png | 常驻睡眼补丁，后发摆动放慢一倍，头顶飘 Z |

工具调用失败（PostToolUseFailure）不切换状态，只在当前画面上闪一下汗珠，参数在 manifest.json 的 reactions 里。工具失败很常见，Claude 通常会自己接着修，做成完整状态会频繁闪烁。

具体参数都在 manifest.json 的 states 里，preview/state-demo.html 内嵌了同一份 manifest 来播放；改了 manifest 之后演示页需要重新生成。

## 叠放顺序

舞台 119×153，角色整体下移 24 像素，上方留给特效。从下往上：后发（hair_c / hair_l / hair_r 之一）→ 当前状态的主体 → 眼睛补丁（眨眼时）→ 嘴巴补丁（说话时）→ 特效。

两种图层做法：

- 补丁：只含变化的像素，其余透明，叠在主体上。只适合原地变色的差分，比如眨眼、张嘴。
- 整张替换主体：改了手臂位置的状态必须用这种。补丁只能往上盖像素、不能擦掉原有像素，叠出来会和原来的手臂、袖子重影，后发也透不出来。

## 处理流程

1. grid.py：估计每张原图的像素网格周期和相位，按格子中心取中位色，还原成真实分辨率（输出 lr.npz）
2. build.py：第一版流程。对齐、k-means 统一 32 色调色板（palette.npy）、提取眼睛和嘴巴补丁、手臂层
3. v2.py：把主体图和三张后发按原图网格采样（输出 lr2.npz），检查对齐与摆动幅度
4. build2.py：第二版流程。量化新图层、清除孤立像素、裁剪到 119×129 并导出
5. build3.py：第三版流程。把 12 到 19 号图对齐到主体网格。12 到 17 号和 19 号导出为整张主体：只取手臂、电脑这些成片变化区域的新像素，其余沿用 main.png；18 号睡眼只在眼睛区域变色，导出为补丁 eye_sleep.png。只取成片变化区域是为了避免 AI 在脸和裙子上的细微噪声导致切换时闪烁；按键帧由手部块下移 1 格得到；感叹号、思考点、星星、Z、汗珠、乌云等特效按调色板手绘生成。路径按脚本位置推算，可直接运行
6. idle.ts + idle.html：早期预览页源码

build.py、build2.py、v2.py、grid.py 里的输入路径是对话环境里的绝对路径，本地重跑时需要改成 source_images 下对应的文件名。

## 生成新差分的经验

- 每条修改开一个新对话，只上传一张底图，只发一条指令
- 新状态都在 07_no_back_hair.png 上改，产出直接就是主体，后发层可以复用；后发差分则上传 08 号后发图
- 多帧动作（比如抬手的过渡帧）以已经定稿的那一帧为底图来改，而不是各自从 07 出发，否则手臂画法对不上，连播会跳
- 提示词里写明"其他所有像素保持完全不变，画布尺寸、位置、背景都不变"，并把动作写具体：手的高度、掌心朝向、移动几格
- 手不要举过头顶，头顶已经贴着裁剪框上沿
- 摆动类差分要给出具体幅度，发梢偏移约 8 到 12 个像素格效果最好
- 背景统一用 #FF00FF 品红
- 闭眼类表情要写明弯曲方向：笑眼是往上弯的弧，睡眼是往下弯的 U 形，否则 GPT 容易都画成笑眼
- 特效层颜色可以超出 32 色调色板（比如汗珠的浅蓝），角色本身的图层不行
- 给其他 AI 的提示词默认用英语
